# Solmu

Sijaintipohjainen sienipeli Turusta. Prototyypit toimivat suoraan selaimessa (GitHub Pages).

- `index.html` – aloitussivu
- `koti/` – kotipeli (kasvatus, markkina)
- `ulko/` – ulkopeli (löydöt kävellen, GPS)
- `iso/` – kokeilu isometrisestä 3D-kartasta
- `blender/` – mallit ja pikselitaiteen renderöintiputki
- `docs/` – ydinvisio ja prototyyppien tila

Kehitysohjeet: `CLAUDE.md`.
